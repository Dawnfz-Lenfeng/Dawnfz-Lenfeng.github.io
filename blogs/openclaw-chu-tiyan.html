OpenClaw 初体验

说实话，第一次听说 OpenClaw 的时候，我内心是有点不屑的。

不就是一个 Agent 吗？Claude Code、Cursor 这些工具我已经用得很顺手了，还需要另一个「给普通人用」的玩意儿？感觉就是套壳而已。但架不住我每天通勤时间实在太长了，车上只能玩手机，很多想做的事情都做不了。于是我就想，要是能有个东西让我在手机上远程操控服务器干点事情，该多好。

抱着试试看的心态，我装了 OpenClaw。用了一段时间后，我发现我错了。

第一个让我改观的是 Memory。以前用 Claude Code，每次开启新对话都是白纸一张，我得把上下文重新说一遍——我是谁、项目是什么、工作目录在哪……说得都快吐了。OpenClaw 会记住这些琐碎的东西，省去了大量重复沟通。就像一个真正认识你的助手，而不是每次都要重新面试的临时工。

我第一次意识到 Memory 的价值。它不只是「记住信息」，而是让 Agent 有了延续性——知道你是谁、怎么说话、关心什么。智力加记忆，再配上 Skills 作为能力，整个东西就活起来了。

说到 Skills，我一开始以为就是什么「高级提示词工程」，包装了一下而已。直到我自己试着写了一个自动博客的 Skill，才发现不是那么回事。这套体系做得挺完善的，不是简单的模板套用。

说到这里有点黑色幽默——这篇博客就是我用自己写的博客 Skill 生成的。套娃了属于是。

不过 OpenClaw 真正打动我的，还是「手机作为随时终端」这个点。以前总觉得手机受限太多，干不了什么「真正的工作」。现在通勤路上就能写博客、查代码、管理服务器。手机终于不再是「只能刷短视频的娱乐设备」，而是成了一个生产力工具。

从最早的 Agent，到 Claude Code、Cursor，再到现在 OpenClaw，我越来越能感受到 AI 带来的冲击。生产力被解放的程度，简直不可思议。

不得不说 Anthropic 真厉害，提出的这些概念确实有用。不过现在各家 Agent 的 Memory 都是各管各的，如果能有一个通用标准，Memory 可以在各个 Agent 之间迁移——就像数据有了端口，Agent 之间不再壁垒分明——那应该会很有意思。

也许过几年回头看，今天的一切还只是个开始。也可能什么都看不到了，谁知道呢。
